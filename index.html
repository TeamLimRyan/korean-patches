About

이 번역방에 대하여

임라이언이 틈틈이 만드는 비공식 한국어 패치를 모아 두는 자리입니다. 텍스트와 글꼴은 물론 UI 이미지, 한글 이름 입력, 한국어 레이아웃 보정까지 손을 대며, 원본 게임의 동작을 해치지 않는 선에서 최대한 자연스럽게 다듬는 것을 목표로 합니다.

모두 비영리 개인 작업이고, 각 게임과 상표·원본 데이터의 권리는 해당 권리자에게 있습니다. 패치에는 원본 게임 파일이 포함되어 있지 않으므로 정품을 보유한 상태에서만 사용해 주세요. 공식 배포본은 아래 GitHub Releases 링크에서만 제공합니다.

지원 환경과 설치 방법
v1.01 사용자는 먼저 원본 복원부터. v1.01이 적용된 폴더에 v1.02를 바로 적용할 수 없습니다. 가지고 있는 v1.01 패처에서 원본 복원을 실행한 뒤 v1.02를 적용하세요. 복원이 거부되면 게임 폴더에 dinput8.dll이 남아 있는지 확인해 삭제하고, Steam의 게임 파일 무결성 검사로 원본을 복구한 뒤 적용하면 됩니다.

지원 환경

  • Steam 정식판 태합입지전 V DX (App ID 1842810)
  • 게임 버전 Ver.1.2.1.0 / public build 9163702
  • 원본 Taiko5DX.exe SHA-256 10C69BAB…B565A2 와 일치하는 설치본
  • Windows x64 · 별도 .NET 설치 불필요 (단일 EXE 패처)

설치

  1. 게임이 실행 중이면 완전히 종료합니다.
  2. ZIP을 별도 폴더에 모두 압축 해제합니다. ZIP 안에서 EXE를 직접 실행하지 마세요.
  3. Taiko5DX_Korean_Patcher.exe를 실행합니다.
  4. Taiko5DX.exe와 data 폴더가 함께 있는 게임 최상위 폴더를 선택합니다.
  5. “지원되는 원본 게임 확인 완료”가 표시되는지 확인합니다.
  6. 한글 패치 적용을 누르고 완료 메시지를 기다립니다.

복원

  • 원본은 게임 폴더 밖 %LOCALAPPDATA%\Taiko5DXKoreanPatcher\Backups에 자동 백업됩니다.
  • 같은 패처에서 해당 게임 폴더를 선택하고 원본 복원을 누르면 되돌릴 수 있습니다.
  • “중단된 작업 복구 필요”가 뜨면 게임을 실행하지 말고 중단 작업 복구를 먼저 누르세요.
