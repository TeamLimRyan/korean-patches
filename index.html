이 번역방에 대하여

임라이언이 틈틈이 만드는 비공식 한국어 패치를 모아 두는 자리입니다. 텍스트와 글꼴은 물론 UI 이미지, 한글 이름 입력, 한국어 레이아웃 보정까지 손을 대며, 원본 게임의 동작을 해치지 않는 선에서 최대한 자연스럽게 다듬는 것을 목표로 합니다.

설치

  1. 원본 본편 CCI와 Update 4.0 CIA를 준비하고, 결과를 저장할 새 폴더를 만듭니다. 원본은 따로 보관하세요.
  2. ZIP을 풀고, 공식 xdelta3 3.2.2 Windows x64를 받아 xdelta3.exe를 준비합니다.
  3. 패키지 폴더에서 PowerShell을 열고 powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Apply-Patch.ps1" -Role base -Source "<원본 본편.cci>" -Output "<결과 폴더>\YW3_Sukiyaki_KO_base.cci" -Xdelta ".\xdelta3.exe"
  4. 이어서 powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Apply-Patch.ps1" -Role update -Source "<원본 Update 4.0.cia>" -Output "<결과 폴더>\YW3_Sukiyaki_KO_update4.cia" -Xdelta ".\xdelta3.exe"
  5. Azahar: OpenGL 렌더러에서 생성한 Update CIA를 설치한 뒤 생성한 본편 CCI를 실행합니다. 예전 모드가 없는 별도 포터블 사용자 폴더를 쓰세요.
  6. 실기 3DS: 기기 환경에 맞는 설치 도구로 적용합니다. 본편 결과는 CCI, 업데이트 결과는 CIA입니다. 정식 서명된 배포물이 아닙니다.

스크립트는 원본·패치·도구와 결과의 해시를 확인하고 기존 파일을 덮어쓰지 않습니다. 원본 전체 해시가 다르면 내부 영역을 대조해 호환 적용하고, 결과 옆 .verification.json에 기록을 남깁니다. 이때 결과의 전체 해시는 아래 값과 다를 수 있으니 적용기의 PASS를 확인하세요. xdelta UI나 Delta Patcher로 직접 적용하는 것은 전체 해시가 기준과 같은 원본에서만 가능하며, 결과 SHA-256을 꼭 대조하세요. 제거는 세이브를 보관한 뒤 한글 업데이트를 지우고 원본 Update 4.0과 원본 본편으로 되돌리면 됩니다. 예전 LayeredFS판 v0.2.1(게임 데이터 0.2.0용)은 릴리스 목록에 남아 있습니다.
